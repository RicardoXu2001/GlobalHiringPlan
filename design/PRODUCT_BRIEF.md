# 《夜班回路》（开发代号）产品范围

targetFinish: 可在 Windows Godot 中完整游玩的重构切片，采用 ART-1.0 像素场景、角色、HUD 与反馈。

| 项目 | 范围 |
| --- | --- |
| 作品方向 | 原创单人 Roguelike RPG，工厂调查、战斗构筑、证据与主动回溯 |
| 名称与主角 | 旧标题停用，正式名待选；《夜班回路》为开发代号。主角固定称为 09 |
| 当前交付 | 《夜班回路》0.2，保留原序章；首组三小怪关＋守门人、心核接驳、随机武器铺、强化与再出发的入口遭遇 |
| 完整单轮目标 | 七组各「三个小怪关＋一个区域 Boss 关」，每组回中心合并、升级与武器铺整备，最后独立古神降临关；21＋7＋1＝29 个战斗关，尚未实现 |
| 中心与构筑 | 同一轮内七次返回安全中心，逐件接入脏器；武器铺随机供货、替换装备或强化当前武器。普通工料与可选圣痕提取分开结算 |
| 平台与语言 | Windows 桌面，Godot 4.5.1，横屏、键鼠、中文、离线。发行目标为 Steam |
| 体验假设 | 固定斜俯视 2D、小型实时动作战斗、检修员身份与停机后的求救 |
| 视觉 | 高对比发光像素，暗底、四组功能亮色、同一像素密度 |
| 原创边界 | 用户参考只控制明暗、像素色块和尺度关系。发行资产使用原创角色、地图、标识与构图 |

背景主线已确认：能源枯竭后，降临救世的圣骸被人类囚禁改造成工厂。改造方案来自伪装成人们口中「天使」的古神胚胎，工厂暗中为它吸取神力、完成孵化。拥有潜在神性的男主接到圣骸的真实求救；系统借升级诱发其神力，并利用营救行动推进自身孵化。完整设定见[世界观圣经](WORLD_BIBLE.md)。背景暂不继续扩写，后续制作重点为 B-17 后的关卡、三类敌人、战斗强化与选择回响。

七组四关、七次中心整备与独立终局的主线结构已确定。0.2 已验证首组实现路径；区域顺序、扩展装备槽、后续商店经济、单轮时长、随机结构、结局参数与发行排期由后续切片验证。具体实现边界以[游戏策划案](GAME_DESIGN.md)和[开发路线图](ROADMAP.md)为准。
