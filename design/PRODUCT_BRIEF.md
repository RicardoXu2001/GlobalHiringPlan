# 《牛马公司》产品范围

targetFinish: 可在 Windows Godot 中完整游玩的重构切片，采用 ART-1.0 像素场景、角色、HUD 与反馈。

| 项目 | 范围 |
| --- | --- |
| 作品方向 | 原创单人 Roguelike RPG，工厂调查、战斗构筑、证据与主动回溯 |
| 当前交付 | 《夜班回路》0.1，接收厅 → 压力车间 → 回溯 → B-17 |
| 平台与语言 | Windows 桌面，Godot 4.5.1，横屏、键鼠、中文、离线。发行目标为 Steam |
| 体验假设 | 固定斜俯视 2D、小型实时动作战斗、检修员身份与停机后的求救 |
| 视觉 | 高对比发光像素，暗底、四组功能亮色、同一像素密度 |
| 原创边界 | 用户参考只控制明暗、像素色块和尺度关系。发行资产使用原创角色、地图、标识与构图 |

完整战役的方向为追查危机、逐步找到母体并面对孵化后的系统。正式战斗形态、单轮时长、随机结构、结局与发行排期由后续切片验证。当前工作以[游戏策划案](GAME_DESIGN.md)和[开发路线图](ROADMAP.md)为准。
