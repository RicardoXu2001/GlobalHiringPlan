# 夜班回路 · 0.2 首组整备原型

targetFinish: 可在 Windows Godot 中完整游玩的重构切片，采用 ART-1.0 像素场景、角色、HUD 与反馈。

范围、游戏规则与资产分别见 [产品范围](PRODUCT_BRIEF.md)、[游戏策划案](GAME_DESIGN.md) 和 [美术圣经](ART_DIRECTION.md)。

当前交付为一组四关、一次中心合并／换装与再出发的完整闭环，同时保留 0.1 的调查序章。完整七组、七次合并与终极 Boss 的 29 关战役仍未实现。

experienceProfile: hybrid

保真顺序：接入并选择模块 → 躲避和攻击 → 停机取证 → 玩家确认回溯 → 用原件进 B-17。只有主动回溯提交迭代，重试和退出继续各有单独入口。状态与故事证据一起可见。

新增主路径：标题「开始首组远征」→ 选武器 → 三个小怪关 → 压维守卫 → 心核与 30 工料 → 中心接驳 → 武器铺买铆枪／强化／有限刷新 → 保存继续 → 肺叶入口遭遇 → 结果与重开。输入保持 WASD、E、J／鼠标、空格、Esc。

不变量：通关奖励只结算一次；返中心不等于故事回溯；接驳一次且带来 +1 伤害；初次武器位强化 +2 伤害且换装保留；商品 12、强化 10、刷新 6 且仅一次；退出继续保留库存与已提交状态，未完成遭遇从入场检查点恢复；死亡使本次远征记录失效。首版仅一个装备位，护具与电容互换。

招牌时刻：接驳后中心长出心核并开始搏动；带着新铆枪与原强化等级再次出发。其余六组、完整三槽装备与终战不得标作已交付。

Windows 桌面、Godot 4.5.1、中文、横屏键鼠、离线单人。世界 640×360 最近邻整数放大，UI 独立排版。像素图层、局部光与工厂音效均在本地运行，回溯采用引擎内短转场。用 Godot 导入 [rpg/project.godot](../rpg/project.godot)，或运行 [试玩启动器](../试玩重构版.cmd)。在仓库根目录执行 `& ./rpg/验证.ps1` 复现验证。[机器事实](../qa/verification.json)

实际运行环境为 Windows、Godot 4.5.1 stable、OpenGL Compatibility、RTX 4060 Laptop GPU、1280×720。测试入口用 Godot 的键鼠事件走通流程，保留标题、探索、战斗和结果帧。正式资产精修、真人平衡和独立包待验。[QA 报告](../qa/QA_REPORT.md)

资产参考为两张用户提供的[生体工厂原型板](visual-targets/夜班回路：生体工厂原型板.png)与[武器原型板](visual-targets/夜班回路：武器原型原型板_gbc.png)。场景与角色按 ART-1.0 重新用源像素制作，原型板不作为可直接裁切的精灵表。新增特效用本地 PixelFX 的 hit-spark 与 collect-burst 重配色后烘焙。工具链为 Python／Pillow、Node、Godot；运行时离线，不依赖 JavaScript 或外部服务。
