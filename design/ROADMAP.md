# 《夜班回路》开发路线图

当前工作分支为 `Develop_Rebuild`。以试玩能证明的变化推进里程碑。

2026-11-12 已实现 0.2 首组整备原型。沿用[世界观圣经 v0.6](WORLD_BIBLE.md)：主角称为 09，公众所称「天使」是古神的伪装；旧标题停用，《夜班回路》暂作开发代号。完整单轮的 29 个战斗关与七次返中心仍是战役目标，下表区分当前实现与后续计划。

| 顺序 | 交付 | 验收 |
| --- | --- | --- |
| 已实现 · 0.1 切片 | 接收厅、压力车间、B-17，短弧与探针，停机取证、主动回溯和检查点 | Windows Godot 从新局打到旁路结算，重开和战败重试可用。[QA 记录](../qa/QA_REPORT.md) |
| 下一步 · 真人试玩与可读性 | 让新玩家分别尝试近战与远程。校准攻击窗口、交互提示和视觉层次 | 记录能否自行走到终端、读懂 Boss 预警、解释为什么要回溯。检查 720p、1080p、字号与低动效 |
| 内容优先 · B-17 检修井 | 追踪真实求救，发现感觉组织，选择提取强化或保留并修复接线，再汇入供给通道 | 操作引起可复核的痛觉／声音变化，两路都有完整结果与可辨认的行动差异；回访读取实际选择 |
| 内容优先 · 普通遭遇与一次强化 | 先制作孵化异变体，验证扑击、闪避与反击；测试短弧突进斩／探针穿透脉冲的候选强化，再考虑保护机制与感染工人 | 两件武器各走通两路，不额外提取仍能完成；攻击与受击可读，重试、读档和回溯不会串入未选后果 |
| 已实现 · 0.2 首组闭环 | 三个小怪关、32 强度压维守卫、心核、返中心合并与恢复、有限随机武器铺与肺叶入口 | 实机输入走通首组、接驳、购买铆枪、强化、刷新、磁盘恢复与新构筑遭遇；原序章同步回归。[QA 记录](../qa/QA_REPORT.md) |
| 下一步 · 首组真人校准 | 分别试玩短弧、探针与铆枪，校准敌人预警、装甲守卫窗口、接驳指引和单装备位取舍 | 新玩家能解释格挡与受伤原因，并自行返回中心、完成换装；检查文字大小与低动效 |
| 后续 · RPG Demo | 经验证的关卡和构筑组合、完整阶段结果、Windows 独立构建 | 干净机器可安装或启动、正常保存和继续，真人从首次进入到结局 |
| 完整战役 · 28＋1 关 | 扩展七组「三小怪＋一 Boss」，每组返中心逐件合并与换装，最终进入第 29 关的古神降临战 | 21 个小怪关、7 个守门人关与 1 个终极 Boss 关准确闭合；七次合并与商店更新可回读，中心不计战斗关，最后整备可用，长流程可保存继续 |
| 后续周目与多结局 | 新证据、支路、构筑与核心处理改变最终战和营救结果 | 每轮保留七区完整旅程；至少两组实际选择产生不同战斗条件与结算，旧阈值按新单轮预算重算 |

先用已实现的一组四关与中心循环校准，再扩展全部七组。完整战役时长、扩展装备随机池、后期经济、更多脏器能力和 Steam Demo 排期均待切片反馈。设计依据为[游戏策划案](GAME_DESIGN.md)。
