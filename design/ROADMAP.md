# 《夜班回路》开发路线图

当前工作分支为 `Develop_Rebuild`。以试玩能证明的变化推进里程碑。

| 顺序 | 交付 | 验收 |
| --- | --- | --- |
| 已实现 · 0.1 切片 | 接收厅、压力车间、B-17，短弧与探针，停机取证、主动回溯和检查点 | Windows Godot 从新局打到旁路结算，重开和战败重试可用。[QA 记录](../qa/QA_REPORT.md) |
| 下一步 · 真人试玩与可读性 | 让新玩家分别尝试近战与远程。校准攻击窗口、交互提示和视觉层次 | 记录能否自行走到终端、读懂 Boss 预警、解释为什么要回溯。检查 720p、1080p、字号与低动效 |
| 后续 · B-17 后第一段 | 增加可核对的线索、一个可执行的路线差异和读取构筑的世界回应 | 两条选择带来可辨认的行动差异。复测读档、重试、回溯与证据归属 |
| 后续 · RPG Demo | 经验证的关卡和构筑组合、完整阶段结果、Windows 独立构建 | 干净机器可安装或启动、正常保存和继续，真人从首次进入到结局 |
| 战役 | 母体揭示、多轮迭代与系统孵化，最终回应最初危机 | 关键证据与玩家行动在后续关卡回读，终战检验这一链条 |

单轮时长、战斗形式定稿、随机路线边界和 Steam Demo 排期均待切片反馈。设计依据为[游戏策划案](GAME_DESIGN.md)。
