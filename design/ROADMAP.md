# 《夜班回路》开发路线图

当前工作分支为 `Develop_Rebuild`。以试玩能证明的变化推进里程碑。

2026-11-12 已实现 0.2 首组整备原型，并在 0.2.1 中纠正整图替换，接入模块化场景与真实动作初版。沿用[世界观圣经 v0.6](WORLD_BIBLE.md)：主角称为 09，公众所称「天使」是古神的伪装；旧标题停用，《夜班回路》暂作开发代号。完整单轮的 29 个战斗关与七次返中心仍是战役目标，下表区分当前实现与后续计划。

| 顺序 | 交付 | 验收 |
| --- | --- | --- |
| 已实现 · 0.2.2 战斗与环境反馈 | 120ms 输入缓冲、闪避取消、短弧三段表现、差异顿帧与击退、分层音效；有高度的像素碎屑、落地痕迹与冷却罐连锁 | 两条完整路径回归，并检查输入队列、资源不变、连锁、落地、粒子预算、低动效与重开清理；真人手感仍待试玩 |
| 已实现 · 0.2.3 表现与碰撞 | 身体帧和武器姿势共用动画时钟，加入环境声和危险音乐层，重排菜单、HUD 和装备卡，接入物件与门扇碰撞 | 序章、首组远征、配置重载、各菜单焦点与碰撞回归 |
| 下一步 · 手感与反馈校准 | 分别试玩三件武器，校准缓冲宽容度、停顿、击退、握持和局部材质反应；保持危险可读 | 记录误操作、被打原因与帧间脱节；完整逐像素液体／燃烧／地形破坏需单独设计验证 |
| 已实现 · 0.1 切片 | 接收厅、压力车间、B-17，短弧与探针，停机取证、主动回溯和检查点 | Windows Godot 从新局打到旁路结算，重开和战败重试可用。[QA 记录](../qa/QA_REPORT.md) |
| 下一步 · 真人试玩与可读性 | 让新玩家分别尝试近战与远程。校准攻击窗口、交互提示和视觉层次 | 记录能否自行走到终端、读懂 Boss 预警、解释为什么要回溯。检查 720p、1080p、字号与低动效 |
| 内容优先 · B-17 检修井 | 追踪真实求救，发现感觉组织，选择提取强化或保留并修复接线，再汇入供给通道 | 操作引起可复核的痛觉／声音变化，两路都有完整结果与可辨认的行动差异；回访读取实际选择 |
| 内容优先 · 普通遭遇与一次强化 | 先制作孵化异变体，验证扑击、闪避与反击；测试短弧突进斩／探针穿透脉冲的候选强化，再考虑保护机制与感染工人 | 两件武器各走通两路，不额外提取仍能完成；攻击与受击可读，重试、读档和回溯不会串入未选后果 |
| 已实现 · 0.2 首组闭环 | 三个小怪关、32 强度压维守卫、心核、返中心合并与恢复、有限随机武器铺与肺叶入口 | 实机输入走通首组、接驳、购买铆枪、强化、刷新、磁盘恢复与新构筑遭遇；原序章同步回归。[QA 记录](../qa/QA_REPORT.md) |
| 下一步 · 首组真人校准 | 分别试玩短弧、探针与铆枪，校准敌人预警、装甲守卫窗口、接驳指引和单装备位取舍 | 新玩家能解释格挡与受伤原因，并自行返回中心、完成换装；检查文字大小与低动效 |
| 已替代 · 0.2.1 整图试接 | 按用户确认样稿接入 18 张母稿，覆盖现有角色、武器、敌人、Boss、房间、装置与装备；1280×720 场景渲染，UI 图标等比适配 | 原序章与远征原生回归；核对脚点、握持、危险边界和卡片图标。完整逐帧动作、所有字号与多 DPI 仍待后续 |
| 已接入 · 模块与动作初版 | 12 个场景模块、64 个角色／敌人姿态帧、独立门扇及 Boss 部件动作；整房间与静态人物图退出世界绘制 | 两套原生路径回归、实际输入动态采样；最终视觉确认与动作细修待后续 |
| 美术后续 · 动作与适配 | 完整方向动作、逐帧握持与装备侧别清理、前景遮挡、全屏与不同显示尺寸 | 不漂移脚点、不更换角色身份，攻击和死亡与既有规则同步；字号和交互标签不被裁切 |
| 后续 · RPG Demo | 经验证的关卡和构筑组合、完整阶段结果、Windows 独立构建 | 干净机器可安装或启动、正常保存和继续，真人从首次进入到结局 |
| 完整战役 · 28＋1 关 | 按 [完整远征设计](LEVEL_ROUTE.md) 制作 06–29 关及后六次返中枢。优先完成肺叶二、三关和呼吸钳，再校准新机制与第二次接驳 | 七次合并与商店更新可回读，远征能保存继续，最后整备后进入独立终战 |
| 后续周目与多结局 | 新证据、支路、构筑与核心处理改变最终战和营救结果 | 每轮保留七区完整旅程；至少两组实际选择产生不同战斗条件与结算，旧阈值按新单轮预算重算 |

先用已实现的一组四关与中心循环校准，再扩展全部七组。完整战役时长、扩展装备随机池、后期经济、更多脏器能力和 Steam Demo 排期均待切片反馈。设计依据为[游戏策划案](GAME_DESIGN.md)。
