# 《牛马公司》游戏策划案

experienceProfile: hybrid

当前可玩版本为 **《夜班回路》0.1**。它验证一轮调查、一次构筑、一场 Boss 战，以及证据如何改变下一轮。斜俯视 2D、实时动作、检修员身份与厂内求救是切片假设。

## 整部游戏的方向

一场危机把男主引向工厂。系统主动提供升级，帮助他接近危机源头。每一次 Boss 胜利都带来局部成果，例如停掉生产设备、打开一条路、救出眼前的人或取得原件。只要最初危机还在，玩家就得决定是否启动回溯，带着新证据重走一段熟悉的路线。

工厂深处的母体是由湿件组成的超级计算机，也是正在孵化的古神胚胎。系统确实帮助男主变强，同时从他的构筑、战斗与回溯中取得实战数据。多次迭代后，胚胎获得实体。一路协助玩家的系统成为最终 Boss，可以回收玩家亲手用过的战术。最后一战要让玩家用跨周目取得的证据和能力，面对最初危机的真正根源。

| 揭示阶段 | 玩家可核实的发现 | 发现如何改变行动 |
| --- | --- | --- |
| 第一轮 | 设备停机后求救仍在继续，日志指向 B-17 | 保留原件，主动回溯，走之前锁住的旁路 |
| 确认迭代 | 同一设备留下不同版本的记录，系统知道玩家已经用过的手段 | 比对原件、质证系统、改走其他供给线 |
| 找到母体 | 活体节点连接供给设备，系统的升级回执与母体活动相互印证 | 进入供给层，追查危机与湿件的关系 |
| 孵化与终战 | 系统获得实体，识别曾帮助玩家练成的战术 | 带着已有证据改变终战打法，处理危机 |

首行及第二行的旁路发现已在切片中呈现。后续关卡、母体能力与最终战仍处于设计阶段。回溯究竟是平行世界、重建现实还是另一种状态，等真相线定稿。

## 玩法与进度规则

**选路 → 探索 → 取得技能或装备 → 战斗并取证 → 核实局部结果 → 决定是否回溯。**

- **场内判断**围绕站位、威胁预警和攻击窗口。构筑要带来新招式、新的应对时机或可达路线。
- **局内成长**来自探索、战斗和有限的构筑选项。切片只选一次模块。多模块联动、装备组合和随机路线需要后续证明有取舍。
- **跨局成长**保留可核对的证据。后续可加入从证据获得的权限和行动，至少有一项实际改变下轮可达区域、交互或敌方反应。
- **系统迭代**由主动确认回溯提交。切片保留选用的模块，并在 B-17 签收记录回读。后续可让系统推荐、敌人策略及同一地点的设施变化跟随经过验证的玩家行为。
- **重试、读档、回溯**各有明确入口。战败从当前轮起点重试。退出后从已写入的检查点继续。回溯带原件回到接收厅，并清除本轮模块和战斗状态。

## 当前切片

| 阶段 | 玩家行动与压力 | 可观察结果 |
| --- | --- | --- |
| 接收厅 | 沿琥珀色地灯接入青色终端，选短弧或探针。西侧 B-17 起初缺原件 | 东侧压力门解锁 |
| 压力车间 | 按预警离开落点，在护板打开时攻击。可步行、闪避、提前占位 | 压力机停机，右侧日志可取 |
| 核实与回溯 | 停机日志显示 02:14 的求救信号从 B-17 转入。主动确认回溯 | 原件进入检查点，玩家回到同一接收厅，局内模块清空 |
| B-17 旁路 | 用原件开门，读取供给记录 | 记录显示系统在进厂前已签收玩家刚用的模块。门内仍有求救，切片结算 |

开局目标为「接入检修终端」，玩家可在一屏内走到目标。证据只确认转接位置和时间。求救者身份、最初危机的根源以及系统掌握了什么仍待玩家查明。

| 战斗参数 | 当前规则 |
| --- | --- |
| 耐久 | 5 点，每次压降或横扫扣 2 点，第三次受击失败 |
| 压力机 | 24 点结构强度，青色护板打开时才受伤 |
| 短弧 · 棘齿切割器 | 有效距离 54 源像素，宽角、8 伤害，至少 3 次命中。约 50ms 前摇，骨白宽斩与沉的金属冲击 |
| 探针 · 脉冲测距枪 | 有效距离 108 源像素，窄角、4 伤害，至少 6 次命中。约 33ms 前摇，青色窄束与短促电击声 |
| 预警与闪避 | 近距离引出横扫，远距离引出锁定玩家纵列的压降。红框持续约 0.85 秒，闪避保护约 0.16 秒，冷却 0.70 秒 |

短弧适合已靠近开板口的站位。探针适合从远处离开压降后保留出手距离。验收基准包括主动离开危险区再反击，以及留在危险区不动。两种构筑都已在实机自动路径打停压力机，后一基准触发战败。真人难度和操作手感待验证。[QA 记录](../qa/QA_REPORT.md)

命中在出招帧检查距离、方向和开板状态。空挥只出招，格挡会在护板上弹出灰白火花，命中弱点会出现强度变化、武器专属闪光和机体局部反冲。闪避能取消尚未释放的攻击。低动效以静态短标记表达攻击结果。

## 表现与下一步

初入厂区时，钢板、地灯与供给管线有清楚的工业用途。回溯后在同一布局里逐步显露血肉组织，让玩家能认出哪些东西变了。青色交互、琥珀路径、红色危险与紫色异常保持固定语义。正式资产与可读性按[美术圣经](ART_DIRECTION.md)验收。

后续先验证 B-17 里的证据选择能改变一个实际行动，再确定更多构筑、敌人和路线。完整战役、玩法参数与发行里程碑见[开发路线图](ROADMAP.md)。
