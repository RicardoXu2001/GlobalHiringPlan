# 《夜班回路》完整远征设计

本案定义 Windows 斜俯视实时动作 RPG／roguelite 的完整一轮。09 以初始武器进入工厂，完成 **七区各三场遭遇和一个守门人，再加一场古神终战，共 29 个战斗关**。序章 B-17 可选。中枢、Boss 门前安全区和关内证据支路均不计关。现有试玩开放 01–05，其中 05 是肺叶入口。后续房间在本案中交付路线和碰撞灰盒规格。

- **第一幕，确认求救。** 心泵 → 肺叶。先认清前摇和开板，再发现阀门动作会改变求救声。
- **第二幕，核对供给。** 眼 → 喉 → 肠。每二区别系统记录与现场证据，先识别伪造信号，再找到绕开牧者提取线的方法。
- **第三幕，夺回接线。** 脊髓 → 胎室。认识回溯记录、拆除母机对圣骸的控制，在第七次接驳后进入核心内腔。胎室沿用世界观圣经中子宫区域的功能定位。

## 一轮的路线

心泵 → 中枢① → 肺叶 → 中枢② → 眼 → 中枢③ → 喉 → 中枢④ → 肠 → 中枢⑤ → 脊髓 → 中枢⑥ → 胎室 → 中枢⑦ → 核心内腔 → 结算。

每组用第一关的安全观察段引入一种机制，第二关换地形和敌群顺序，第三关组合已学规则并预演守门人招式。**击败本组守门人、带回功能脏器并接驳**是唯一推进门槛。工料、圣痕、真名音节和随机装备可以绕开。每个 Boss 门口保留安全前室，可观察一次静态或演示轨迹、查看耐久和返回该组的第三关出口。已通关房间保持空场。第一次进门后锁战斗出口，守门人停机才放行回中枢。安全前室也作为经玩家确认的休息点。

| 关 | 房间 | 空间与遭遇 | 教学、判定或收益 |
| --- | --- | --- | --- |
| 01 | 供给前廊 | 明亮落点旁留侧闪带，一只失败孵化体 | 站在安全线看完着地圈，再试闪避与反击 |
| 02 | 转运通道 | 双侧通道，感染夜班工沿窄轨攻击，扑击体切后 | 窄轨保持原锁定方向。先杀近处小怪可留下侧向退路 |
| 03 | 拘束侧室 | 两条绕行线包住免疫守卫，夜班工堵直线 | 正面格挡，背面和收招可打。证据支路读到心泵拘束记录 |
| 04 | 压维守卫 | 正面机座，横扫与纵向压降交替 | 压力释放后青灯开板。停机取得**心核**，解除第一道拘束 |

| 10 | 镜片分拣 | 两列反光挡板，工人与观察哨互相掩护 | 地面定向刻纹和闪点同时提示扫描方向 |
| 11 | 失焦廊 | 主路两处可断线点，旁路读原始监控 | 首次出现牧者改过的影像。回收眼区音节，演示锁定后可变向 |
| 12 | 盲巡镜 | 扫视、锁定、打向最后已确认位置 | 在下一次扫描前反击，取得**复眼**。掩体开口始终可通行 |
| 13 | 回声坡道 | 对照两道发声口，地面波前从声源传播 | 音效与波纹同步，用波纹可以在静音时识别安全方位 |
| 14 | 声纹调度间 | 两条波前方向不同，敌群只从已见门口进场 | 保留带状空隙，允许提前绕行或穿越一次波前 |
| 15 | 静默间 | 观察区可试听两份录音，随后打两波小怪 | 保存未改写的音节，观察真声和牧者模仿声的可辨差异 |

| 17 | 循环滤池 | 透明供料管标出两条流路，单只清道虫 | 演示截断阀只关一条线。观察验证后再启用敌方吸收槽 |
| 18 | 双供养线 | 左阀切资源，下道绕守卫，击杀和控场均可过 | 先处理取能敌人可让另一条线失效，防止全场持续叠压 |
| 19 | 沉降罐 | 阀门、近战和周期性副流组合 | 可改接**消化隔离线**并比对音节。离场前预览 Boss 供料口 |

| 21 | 反射弧 | 地面投影先演示一段之前见过的轨迹 | 二次回放使用描边残影，实体释放另有确定的明亮前缘 |
| 22 | 髓鞘栈桥 | 对向预警错开，至少有一条连续通路 | 输入被记录为方向和招式组，真实攻击有起手延迟 |
| 23 | 迭代存档室 | 回放夹一组敌人，旁路读取上一任检修员的记录 | 获取脊髓音节，确认短回溯是母机迭代，预演组合招 |
| 24 | 逆行反射器 | 连用两种已教过的攻击，末招短暂留空 | 每次组合后可反击。脱离束缚的线路唯一授予**神经束** |
| 25 | 胎膜外围 | 双环分流，安静观察再生节点亮起 | 先单独切一个节点练习破坏，让玩家看见核心恢复停止 |
| 26 | 维生架 | 两个再生节点和中脊障碍，覆盖两条路线 | 从侧翼可拆节点，远程和近战各有进入窗口 |
| 27 | 接生台 | 返流、再生和反射投影轮换，中央留回环 | 取回末个音节，可改接**胎室隔离线**。门外可确认终战所用供给 |
| 28 | 维生架主任 | 主体保护两枚再生节点，逐一亮起 | 切断节点打开进攻窗口，取得**生殖核**，回中心做最后接驳 |
| 29 | 核心内腔 · 初啼 | 护栏外看七部件接合，入内后完成三段终战 | 循环／呼吸开窗、复眼／声带捕捉、消化／神经／再生组合；每段保留明确安全侧和可命中的反击窗 |

第一组前三间以已可玩的敌人和动作作为基准。物体底座负责阻挡，脚点排序负责遮挡。先通过灰盒再布置模块化美术。在 640×360 逻辑画布上，控制器实测直行每秒 116px，完整闪避在 60Hz 下走 59.17px，角色脚点半径为 5px。灰盒关键走廊至少留 32px。Boss 场地设置可辨的撤离侧缘，沿主通路从危险边缘到安全处至多 48px，第一次致伤预警至少 0.65 秒。琥珀标通路与出口，青色标设备，敌招同时给出轮廓、方向与倒计时。可选证据支路都能往返。灰盒尺寸和布局候选见 [数据](LEVEL_ROUTE.json)。

## 角色成长与局内经济

**场内闭环**：读招 → 反击 → 清理或救助 → 决定搜证或提取 → 带脏器返中枢 → 恢复、接驳、补给和出发。工料承担常规经验的职责，探索一次也能推进成长。组内完成房间立刻授予清关工料，Boss 奖励一次结算。选择和重试由状态驱动，读档不得重复结算。

| 系统 | 设计数值与决策 |
| --- | --- |
| 耐久 | 基础 5，每组返中心恢复至当前上限。单一装备位包含 +2 上限或 15% 武器冷却缩短。换装当前耐久按上限截断，医疗收益在组末恢复结算。前期轻击目标 1，主力招式 2，重击 3 预留给终战且有长前摇。现有试玩敌招以 2 为基准 |
| 三类武器 | 短弧 8、探针 5、铆枪 3 为首批基准。短弧宽面、连续第三刀加表现。探针保留窄轨穿透，铆枪靠频率与站位安全。三个取舍跨组保持可见 |
| 强化 | 每次返中枢解锁下一档武器位强化，当前档 +2 伤害。首六次返还最多到 +6，第七次用于终局补给和调整。换武器保留档位。心核接入的首次 +1 共鸣沿用首组基准。其他器官给可见功能变化或改变最终战响应 |
| 命中公式 | 实际伤害取基础武器值 + 武器位档位 × 2 + 共鸣加值 + 当前的圣痕收益，再读取目标护板状态。开板取全值，护板正面格挡取 0。装备百分比只作用对应属性，伤害取整一次。低吸收主线计划每区常规战 2–5 刀，守门人 4–18 次有效命中，终战 10–26 次，铆枪按较高攻击频率计 |
| 工料 | 小怪关各 6，守门人 12，每组 30。货架购入 12、一次刷新 6、强化 10。首次 30 的组合就可购入、强化、刷新，余 2，过关无需凑齐商店购买。后续基线维持这些价格，额外词缀作为可选备选池 |
| 装备选择 | 一把主武器加一个装备位。每组首次补货至少一件武器和一件装备，保底均可放弃，当前装备用单独提示。通关解锁新出身选项、词缀组和档案，跨轮成长以选择为主 |
| 圣痕 | 每区一次选择，留证 0、节制提取 1、深度提取 2，本轮额外吸收量 A 范围 0–14。留证可登记本区音节。选择提取会耗掉本轮证物。每两点 A 提供本轮 +1 伤害，上限 +3。接驳终端会预览受影响的终战选项 |
| 目标时长 | 小怪关 50–85 秒，守门人 100–155 秒，返中心整备 55–90 秒，终战 180–240 秒。七组关键路径计划 39–62 分钟，标准目标约 50 分钟。首败高风险区间在第 04–08 关。所有数值依据后续真人实测调整 |

局内存档保存版本、种子、房间与关卡阶段、已结算标记、当前耐久、武器档位、装备、工料、货架和售出索引、脏器／接驳位、A 和已选择的隔离线。离开中途战斗时从本房入场状态恢复，交易与接驳之后即写入。战败失效局内存档。档案另存 K 和已验证的资料、完成结局、跨轮累计吸收；读档、放弃和退出不重发奖励。可选择固定种子来复盘。每个房间按「种子、房间、目的」派生出布局模板、敌群、货架等随机源，战斗与音频随机消耗独立。记录生成版本，避免更新后同种子误判为同一套房间。

## 回溯、同一主线与不同结局

本案在完整第一轮呈现古神降临。关卡主题固定，二周目可以变化敌群顺序、地形模板和守门人已教过的招式排列，同种子与内容版本可复现。每区留一个真名音节，首次即可通过七次留证收齐。「成为圣骸」同时需要高吸收与五个音节，先前积累的档案会为这一选项腾出空间。三条隔离线属于本轮，在肺叶、肠和胎室分别设置。已经掌握证据的玩家可以继续接回对应线路。累计吸收量以结算时每轮一次入档，终战血量在累计 0–7、8–15、16 以上分别为 +0%、+6%、+12%。

中枢⑦明确列出隔离线路、A、K 和可用操作，玩家确认进核心后依次见到降临并挑战初啼。打完才出现终端选择，满足多个条件时让玩家选，通用「继续迭代」始终开放。以下阈值是七区版的设计裁定。

| 结束方式 | 解锁条件 | 玩家明确操作 |
| --- | --- | --- |
| 长夜 | 击败初啼 | 由接驳台提交回溯，下轮按种子重开 |
| 醒 | 初啼战后，K＝7、本轮 A≤2，三条隔离线齐备 | 呼唤真名，等待圣骸回应，再同步解除拘束 |
| 熄灯 | 初啼战后，本轮 A≤2 | 在母机终端确认切断维生，电力和供给一起停止 |
| 接生 | 初啼战后，本轮 A≥10，隔离线未完成 | 将调度权限交给孵化协议，09 接手牧者职责 |
| 成为圣骸 | 初啼战后，本轮 A≥8，K≥5 | 用 09 的神性接管维持机构，替圣骸承担供给 |
| 换班 | 已完成过一次终战，发现镜片分拣区的维修梯 | 主动确认提前离场。保留档案，本轮通关不计入 29 关完成记录 |

结算显示深度、种子、最后伤害来源、关键选择和新解锁。就绪装置短屏提示下一次可选操作，允许结果页立即回标题或重开。故事背景与人物身份以 [世界观圣经](WORLD_BIBLE.md) 为准。原型中的武器数值和已开放房间由 [试玩说明](../rpg/README.md) 记录。

## 验证方式

在仓库根目录执行 `python design/check_level_route.py`。脚本验证 29 个战斗关、七个接驳门槛、离开支路后的可达性和 Boss 前休息段。每个布局按脚点和通路净宽做地面可达检查，500 个种子共抽样 14,500 个房间。数值部分检查常规伤害、各区 Boss 有效命中次数、首组工料账和五种终战后的选项。
