# 《夜班回路》（开发代号）世界观圣经 v0.6

status: 七组四关、中心整备与终局结构确认 · 2026-11-12 · 正式标题待选，玩法参数与完整战役待验证
scope: 承接 0.1 切片（接收厅 → 压力车间 → 回溯 → B-17），向后定义完整战役、多周目结构与多结局
position: 取代此前「公司把神做成了 KPI」的职场讽刺主轴，以及 A–E 五个选题中的「入职 / 排班」两条。定位为动作 Roguelike RPG，不带经营玩法

人类世界能源枯竭，神明出于怜悯，派圣骸降临救世。一个早已存在的古神胚胎觊觎其神力，伪装成被人们奉为「天使」的施恩者，利用人类的贪欲交出工厂改造方案：表面为人类提供能源，暗中把真正的救世者变成自己吸取神力、完成孵化的场所。人们口中的「天使」指这个古神，与圣骸是两个不同的存在。圣骸始终活着，被囚禁并工程化改造；玩家探索的工厂就在它的身体之中。

第一通信号确实是圣骸的求救。拥有潜在神性的主角因此进入工厂，随后接受牧者的指引；系统以升级诱发他的神力，利用他的战斗、解锁与回溯推进孵化。母机是架设在圣骸神经系统上的计算与控制网络，牧者是古神胚胎「初啼」尚未获得完整躯体时的人格表现。

以上为后续制作的背景基准，暂不扩写神系、宇宙史或更多势力。主角标识确定为「09」，旧标题《牛马公司》停用；《夜班回路》暂作开发代号。完整单轮确定为七组区域，每组「三个小怪关＋一个 Boss 关」，组末带回脏器，在中心合并、升级和武器铺整备。七次合并完成后再进入古神降临的终极 Boss 关，共 21 个小怪关、7 个区域 Boss 关与 1 个终极 Boss 关，即 29 个战斗关卡；中心不计入战斗关数。区域顺序、经济参数、结局阈值与时长仍需验证。

## 一、一句话

你接到一位被改造成工厂的存在发出的求救，走进它的身体，用从它身上提取的力量变强，并亲手推动帮助你的系统长成另一个神。

## 二、核心命题

| # | 命题 | 落点 |
| --- | --- | --- |
| 1 | **神性强化即榨取**：牧者诱发潜能的资源来自你要救的那位 | 提取圣痕与圣骸损伤、供给变化产生可核对的对应；普通换装与工程强化另用工料 |
| 2 | **回溯不是恩赐，是迭代** | 母机的自我维护；存档即固件，版本号每轮回 +0.1 |
| 3 | **营救仍然可能，拘束已经深入身体** | 圣骸有感受、记忆和逃离的意愿；解除一段拘束带来真实的局部自由 |
| 4 | **最终 Boss 是你亲手拼起来的** | 七次返中心接入脏器，逐步装配核心中的躯体；本轮处理方式、额外供给与迭代记录影响降临后的招式和破绽 |
| 5 | **名字即知识，而你没有名字** | 神有真名，玩家只有工号；这既是恐怖点，也是真结局的门槛 |

## 三、命名体系

称谓同时包含身份与骗局。人们口中的「天使」是古神伪装出的施恩者形象；真正发出求救的圣骸则被记录成可以利用的「羔羊」。玩家逐步发现，人们赞颂的方案提供者正是囚禁与孵化阴谋的受益者。

| 称呼来源 | 名称 | 实际所指与含义 |
| --- | --- | --- |
| 人们与厂区信徒 | **天使** | 古神伪装的施恩者身份；人们相信它赐下工厂方案、解决能源危机，实际是在替它建设孵化场 |
| 教典与档案 | **羔羊** | 圣骸，被献祭的那一位，只有编号，没有名字 |
| 玩家要营救的存在 | **圣骸** | 被囚禁并工程化改造的活体救世者，仍能感受、思考与求救；与被人们称为「天使」的古神不同 |
| 玩家的资源（升级晶体） | **圣痕** | 从圣骸伤口里长出来的结晶 |
| 系统自称 | **牧者** | 古神胚胎的系统人格。语气像照护者：「我会看护你，直到你不需要被看护」 |
| 母机（超级计算机） | **座天使** | 架设在圣骸神经系统上的计算与控制网络，利用其认知、梦境和身体维持运转；是设施名称 |
| 古神胚胎与终局实体 | **初啼** | 与公众信奉的「天使」、系统牧者同属一个古神的不同身份或表现；先于工厂存在，最终获得完整实体 |

命名借用通用宗教与工业词汇，其角色、历史、关系和视觉由本作建立。制作口径区分「天使」这一公众称号、圣骸这一真实求救者，以及座天使这一母机名称。圣骸奉命救世的经历不变，但公众对「天使」的信仰指向伪装的古神。「圣骸」这个称呼与它仍然活着的事实之间存在落差，档案中的设备术语也会掩盖其痛觉和意愿。神明与古神的具体谱系不在当前制作范围内。

## 四、世界结构

- **圣骸**：被囚禁的活体高维生命。身体内部嵌入了厂房、维生设备、替代器官和提取管网。深处保留意识与原生组织的核心，玩家沿途经过的区域也属于它的身体。
- **工厂**：从圣骸体内向外扩张的工业设施。原生组织、人工替代器官、拘束与提取装置共同构成可探索的空间。钢板、管道和车间都有工程用途，可以逐步追溯它们接入了什么组织。
- **座天使**：人类架设在圣骸神经系统上的母机，承担计算、监控、调节和拘束。其网络具有行星尺度，当前厂区是玩家接触的局部节点。它与圣骸、初啼各自具有明确边界。
- **七腔室**：喉、心泵、肺叶、眼、肠、脊髓、子宫，作为七组区域与功能的称呼。每组由三个小怪关与一个守门人 Boss 关构成，产出一件功能脏器。人类将原生生理结构接入工业设备，改造与维护痕迹需要在场景中可辨认。「子宫」暂指人工生殖组织培养区，产出第七件功能脏器；它与最终的孵化核心是两个不同地点，名称可继续调整。
- **整备中枢（中心，暂名）**：七组之间重复返回的安全外环，含脏器接驳、升级、武器铺与档案。牧者让 09 每次归来都接入新脏器，表面是逐步修复求救者，实际通过管网向内侧核心装配躯体。常规返回属于同一轮，不是故事回溯。
- **孵化核心**：中心接驳的深处内腔，独立的第 29 个战斗关卡。七次合并完成后，09 仍可在中心最后整备，确认进入内腔才见证古神降临与最终战。
- **牧者**：母机中的系统人格，也是初啼尚未获得完整躯体时的表现。它引导男主探索、升级、战斗和回溯，借实际行动推进胚胎的成长。
- **初啼**：觊觎圣骸神力的古神胚胎，也是人们口中「天使」的真身。它在工厂建立之前已经存在，借伪装、方案与人类施工获得孵化设施，通过提取管网取得神力，通过牧者诱发主角的潜能、取得行为记录并校准自身成长。它与仍然活着的圣骸保持独立的意愿和身份。
- **夜班**：圣骸受控制进入梦境运算和特定生理循环的时段。厂区随其呼吸与循环产生变化，工人将部分现象理解为神的恩典。
- **B-17**：厂区通往井道的门。0.1 的终点，也是整场战役的入口。

空间推进：厂区序章（0.1 验证）→ 中心 →〔一组：三个小怪关＋一个 Boss 关 → 中心合并与武器铺整备〕× 7 → 孵化核心（古神降临与最终战）。正式战役中序章机制应并入既定编排，不额外增加必经战斗关。

### 4.1 可以追查的改造历史

人类世界先经历能源枯竭。神明怜悯苍生，派圣骸降临并主动施救。古神胚胎随后伪装成施恩者，被人们称为「天使」，利用人类对能源的需要和持续占有神力的贪欲，交出工厂改造方案。人类按图施工，逐步把真正的帮助者变成囚徒，却把方案与供能的功劳归于伪装的古神；同一套设备在向世界供能的同时，也将神力导入隐藏的孵化区。

推动工程的人包括获利者、追求突破的研究者，以及担心停机会失去现有生活的人。人类主动承担囚禁与提取的责任，其中大多数人并不知道方案的最终用途。胚胎最初如何接触人类，不再扩写为新的背景支线。

| 阶段 | 设施的原始用途 | 后来的改变与可见证据 |
| --- | --- | --- |
| 救世降临 | 圣骸主动提供神力，缓解能源危机 | 早期记录保留自主援助与供能中止权，后来被删除 |
| 方案落地 | 按人们信奉的「天使」提供的方案建设稳定的能量收集设施 | 新增控制供给方向的阀门、计量与隐蔽支路，供给逐步脱离圣骸意愿，最终流向方案提供者自身 |
| 人工循环 | 用机械辅助或替代部分器官 | 人工心泵和通气设备使它越来越依赖工厂 |
| 神经接管 | 读取、接管和限制感知与动作 | 痛觉和拒绝被档案归入设备异常 |
| 持续提取 | 向人类世界持续供能 | 母机统一调度，隐蔽支路向既存胚胎供给神力，孵化区读取供给与玩家行为 |

### 4.2 玩家逐步发现这里能够感受痛苦

- 拉动阀门后，远处的求救声中断；再次调整时出现可以重复核实的对应。
- 关闭供给后，墙内组织抽动，仪表把它记录为设备振动。
- 提取圣痕与某段管线的新损伤同步，档案随后确认其连接感觉神经。
- 后续原件揭示，早期听过的噪声包含圣骸对玩家操作的回应。

上述表现先提供可观察的因果，再让记录解释含义。关键揭示需要改变一个可执行的行动，例如停止切割、调整阀门、绕开感觉组织或恢复通路。

### 4.3 营救关系与守门人的职责

多数机械守门人来自人类安装的拘束、维生和提取设备。玩家对关键部件的处理需要有具体后果，解除提取或压迫应当恢复一段实际的生理功能。战斗成果会留下可核对的变化。

后期也可能遇到圣骸自身的免疫反应。它未必能辨认携带提取武器的主角。知识路线可以提供安抚、绕行、识别或证明意图的办法。

普通敌人沿三种来源制作：孵化过程中产生的异变体、圣骸原生的保护机制，以及受感染或蛊惑的人类。每种来源应有可辨认的轮廓、行为与处理方式；具体首批敌人见游戏策划案。主角的神性使他能够伤及这些异常存在，但仍会受伤和死亡。

圣骸保留自己的判断。它可以表达拒绝、要求先关闭某处提取，也可以暂时拒绝开放通道。涉及初啼的态度和保护行为仍需结合后续剧情确定。男主通过逐步沟通理解它的意愿，营救因此包含协作和分歧。

## 五、真相的四层

玩家不是一次被告知，而是一层层剥开。每一层都要有一次「可玩」的证据，不能只靠台词。

| 层 | 玩家以为 | 实际 | 证据形态 |
| --- | --- | --- | --- |
| 1 | 求救者被困在厂房深处 | 求救者仍然活着，厂房已嵌进其身体 | 阀门操作、组织反应与求救声发生可重复的对应 |
| 2 | 升级资源可以帮助营救 | 提取资源也在损伤圣骸，并向初啼提供供给 | 管线的新损伤与提取记录、武器升级回执一致 |
| 3 | 牧者提供的成长与任务都在帮助救人 | 牧者是初啼的人格表现，选择有潜在神性的主角，以升级诱发其力量，借营救行动完成孵化 | 原始求救与后来的模仿在录音中可区分，升级回执、开通的支路与胚胎反应相互印证 |
| 4 | 接近核心就能直接带走求救者 | 拘束、维生与算控已深入身体，营救需要逐段解除并理解其意愿 | 玩家已恢复的循环、解开的通路与圣骸的主动回应共同影响终局 |

第一通 02:14 求救确实来自圣骸。牧者随后接管传递渠道，初啼逐渐学会模仿。三者共享部分组织和声音来源，但保有不同意愿；对同一句求救，需要用时戳、上下文和现场反应辨认说话者。

原始求救的真实性保持不变。误导发生在牧者如何解释信号、安排路线和定义「救援进度」。玩家确实恢复过局部循环、救助过眼前的人，这些成果保留；同一行动也可能被系统接入孵化流程，后期允许玩家凭证据改变供给去向。

「天使」身份骗局并入第三层揭示。候选证据是对照教典中的改造方案、母机的执行协议与孵化支路，追出被赞颂的方案提供者和最终受益者是同一存在。夜班工的信仰只作为其相信的说法，不能直接作为圣骸身份的事实证据。

## 六、三幕

**第一幕 · 求救**
拥有潜在神性的夜班检修员接到 02:14 的真实求救；牧者识别其潜能后上线，教玩家怎么活，并将神性共鸣解释为工具兼容。打停压力机后，一段受压迫的循环恢复，求救声变得清晰，日志却显示信号来自更深处。主角取得原件，接受牧者提出的回溯，以进入第一轮无法通行的旁路。

**第二幕 · 怀疑**
每次回溯，厂区有细微差异：同一具检修员遗体出现两次，某扇门上一轮不存在。牧者开始记得玩家做过的事。资源来源暴露，圣痕与圣骸的伤口有关。主角开始区分原始求救与初啼的模仿，取得能质证牧者的材料，并逐步辨认第二、第三位守门人的职责。

**第三幕 · 共谋**
09 在七次归来中依照「修复求救者」的指引逐件合并脏器，中心随之出现搏动、呼吸与注视。最后进入核心，初啼用已经组装完整的身体降临。牧者与人们信奉的「天使」指向同一古神，营救行动也一直被纳入孵化协议。终局 Boss 使用玩家收集的器官能力与留下的战斗记录；先前恢复的生理功能、取得的知识和每次接入的处理为反抗与营救提供实际条件。

三幕是认知推进的三个阶段，可以在一次七区旅程中经历；后续周目通过新证据、路线与选择深化，完整孵化与最终战不要求先刷满若干轮。0.1 内部的短回溯仍是序章教学，不算已通关一次七区战役。

## 七、一轮的结构

- 一轮 = **7 ×（3 个小怪关＋1 个区域 Boss 关）＋1 个终极 Boss 关 = 29 个战斗关卡**。共有七位守门人与一位终极 Boss；中心与七次组间整备不计关数，时长待关卡实测。
- 每组的循环为三个小怪关内探索、战斗与区域操作，击败本组守门人后取得一件脏器，再回中心合并、恢复、升级与随机武器铺整备，确认出发后进入下一组。第七组后仍先回中心，才进入终局。
- 区域内保留支路；七区顺序是否固定、哪些区间可以自由排序，留待关卡连接验证。多周目可以变换支路、敌群、守门人招式与脏器处理方式，不以省略其余四区作为重玩结构。
- **拼装终局**：七次返中心将脏器逐件接入核心，每件都贡献一种可辨认的能力。因为每轮都会收齐七件，终局差异改由脏器状态、额外供给、每次接入的处理与迭代记录产生；不能只靠「有没有取得该器官」变化。

下表为脏器与能力的首轮对应草案，区域顺序、名称与招式尚未定稿。

| 区域 | 收集的功能脏器 | 初啼获得 | 终局表现候选 |
| --- | --- | --- | --- |
| 心泵 | 心核 | 循环与搏动 | 蓄力后恢复，可中断的回血窗口 |
| 眼 | 复眼 | 视觉 | 标记并追踪 09 的位置，以清楚预警检验变向 |
| 喉 | 声带 | 声音 | 用圣骸的音色呼叫「09」，随后发动可读的共鸣攻击 |
| 肺叶 | 肺囊 | 呼吸 | 吐息与周期性气流改变安全站位 |
| 肠 | 消化腺 | 吸收 | 争夺场地能量，玩家可抢先截断输送 |
| 脊髓 | 神经束 | 反射 | 组合已学会的攻击，保留闪避与反击窗口 |
| 子宫 | 生殖核（暂名） | 再生与形体稳定 | 核心组装后维持完整躯体，形成可破坏的再生结构 |

### 7.1 收集、升级与核心合并

七件功能脏器是本轮主线物品，圣痕是可选择提取的强化资源，两者分开计量。主线脏器不能被当作普通货币消耗，正常收齐七件也不直接记为额外吸收量。具体取得形式建议为从守门装置的维生结构中取回已被分离的功能组织，局部组织如何维持、修复与转接需在关卡内交代，避免收集行为与圣骸仍然存活相矛盾。

每次击败区域 Boss，画面明确显示取得的脏器与本区解除的拘束；返中心接入时再显示已合并数量与身体变化。可试验脏器共鸣提供战斗能力，武器铺用工料支持常规换装与工程强化，圣痕则提供可选择的神性诱发；具体效果与数值先用一组验证。

脏器随七次归来逐件合并，不等集齐后再一次性交付。首次标准路线将每次接入呈现为修复任务，提交前展示本次脏器和拟接入部位。第七次合并完成躯体装配，但不自动剥夺购物和最后调整的机会；确认进入第 29 关后，降临演出回收七个部位的对应关系，并开启最终战。真相揭示之后仍让 09 有实际反抗的机会。

后续周目仍沿七区主线到达核心。已掌握的证据可以解锁调整组装接线、隔离额外供给或留下器官破绽的行动，继而改变最终战和结局；这些是待验证的实现方向。营救结局需要回应圣骸意愿，不能只用少捡主线脏器来达成。

中心武器铺每组更新随机武器装备，同时保留当前武器的常规强化渠道；普通采购不要求进一步伤害圣骸。库存、刷新限制与首组经济草案见[游戏策划案](GAME_DESIGN.md)，此处不另建一套规则。

**重复 Boss 的解释**：母机会维修或重建设施，圣骸的部分组织也会再生。重新安装的守门设备读取上次的行动记录，表现为有提示的打法变化。每次重访通过设施、组织和记录的差异交代发生了什么。

## 八、两条进度条

| | 力量（吸收） | 知识（名字） |
| --- | --- | --- |
| 来源 | 吞噬圣痕 | 观察、记录、放弃吸收 |
| 作用 | 变强，打得动更深 | 开门、听懂、拼出真名 |
| 代价 | 喂大初啼，关掉好结局 | 变弱，容错低 |
| 上限 | 无 | 7 个音节 |

两者不能同时最大化。玩家每一轮都在做交易——这是整个游戏的道德骨架，也是重玩价值所在。

结算方式刻意不同：

- **知识跨周目累积**，是解锁型进度（像以撒的结局解锁）：这一轮拿到的音节，下一轮仍然记得。
- **力量本轮重置，但吸收总量永久计入初啼**：刷得越多，往后每一轮的终局 Boss 越厚。玩家很难靠刷把游戏变简单。
- 结局判定看**本轮**的吸收量（A），终局强度看**累计**吸收量（A 总）。所以「醒」和「熄灯」是可以专门开一轮去冲的。

## 九、六个结局

六个结局仍为候选，旧阈值需按七区一轮重算。判定参考 **A 本轮额外吸收量**、**K 名字数（0–7，跨周目累积）**、**R 路线与核心组装处理**。主线收集七件脏器不计入 A；正常战役路线先完成合并、孵化和最终战，再按行动结算，提前离场的彩蛋单列。

| 结局 | 条件 | 内容 | 周目影响 |
| --- | --- | --- | --- |
| **长夜** | 默认 | 本轮完成局部解放，整体营救仍未完成，选择继续迭代 | FW +0.1，回厂，下一轮 |
| **熄灯** | A ≤ 2，击碎座天使 | 算控与供给网络崩溃，维生中断使圣骸死亡，依赖工厂的世界陷入停电 | 解锁「无光」难度 |
| **醒** | K = 7，念出真名 | 圣骸恢复被压制的感知与表达，玩家与它共同解除拘束，第一次以自己的意愿看这个世界 | 真结局，解锁档案终章 |
| **接生** | A ≥ 12（旧候选阈值）且核心未被有效干预 | 最终战未能切断孵化协议，古神真正降临，09 成为下一任牧者；不与每轮必有的孵化演出混为同一条件 | 解锁「牧者」开局 |
| **换班** | 任意腔室找到出口电梯并离开（隐藏） | 走出大门，身后世界继续烧。你在别处接着上夜班 | 彩蛋结局 |
| **成为圣骸** | A ≥ 8 且 K ≥ 5 | 玩家接入维持结构，承担原先压在圣骸身上的部分供给与运算负担；替代的范围和代价待定 | 解锁「同梦」开场 |

设计原则：**真结局要求玩家主动变弱**。「醒」和「熄灯」都要低吸收，玩了几十轮靠刷的玩家，最后一次要靠不刷。这是 roguelike 的反直觉爽点，也是最难的一课。

## 十、恐怖手法

| 手法 | 做法 | 效果 |
| --- | --- | --- |
| 同源声音 | 保留原始求救，逐步加入牧者和初啼对声纹、措辞的学习与模仿 | 玩家能够比对同一句话的不同来源，发现声音的控制权发生了变化 |
| 颜色转向 | 胚胎及背景从交互终端的青色语法逐渐长出紫色异常结构；交互与危险提示保留固定语义 | 熟悉的界面成为陌生生命的一部分，战斗目标仍可读 |
| 底噪 | 工厂轰鸣降频后就是圣骸的哭声 | 环境音即伏笔 |
| UI 即身体 | 升级界面的边框，最后成为 Boss 房间的轮廓与血管 | 玩家每天点的菜单，是它的身体 |
| 档案膨胀 | 文本量随周目增长，地图不增长 | 640×360 下「读」出宇宙，而不是「画」出宇宙 |
| 重复中的差异 | 每轮回厂，走廊里多一具上一轮的你 | 让玩家怀疑自己是不是第一次来 |

## 十一、角色

| 角色 | 设定 |
| --- | --- |
| **09（玩家／检修员）** | 主角的固定称呼与工号均为 **09**，保留前导零。拥有尚未充分觉醒的神性，能对抗异常存在，也因此被牧者选中；升级实际诱发其神力。母机只记录编号，没有记录个人真名，终局 Boss 也呼叫「09」。神性的来源暂不展开 |
| **牧者** | 系统。语气温和、耐心、从不正面回答。称玩家为「09」或「检修员」，没有记录他的个人真名 |
| **圣骸** | 奉神明之命下凡救世，后被人类囚禁改造。始终活着，表达受干预，但仍有感受、记忆、意愿和判断。发出最初的求救，声音疲惫，像隔着很厚的水，能够请求、回应和拒绝 |
| **初啼** | 先于工厂存在的古神胚胎，以「天使」的伪装获得人类信任并交出改造方案，借圣骸的神力孵化。牧者是其人格表现，以救援任务引导主角为孵化服务，并学习模仿「救救我」 |
| **上一任检修员** | 第四腔室。半器官化，还在值班，记不清自己来过几次 |
| **夜班工** | 信奉伪装成「天使」的古神，相信工厂方案是恩赐。提供的信息可能出于真诚，但对恩人的身份与供能代价受到欺骗 |

「09」是已确定的角色称呼，个人真名仍留白。数字来自创作者对 9 的偏好，暂不追加第九代、九位神或必须九周目的背景含义。

### 11.1 神性与升级的边界

主角自身的潜能解释他为何被选中、为何能够战斗；圣骸被提取的神力解释牧者如何加速诱发这种潜能。升级带来的战斗能力真实有效，提取和输送过程中初啼也得到供给。具体分配比例不作为当前数值承诺。

基础攻击与闪避不需要持续提取圣痕才能使用。停止进一步榨取后，玩家仍能依靠基础能力、已取得的技巧和证据路线推进，知识也能提供新的应对方式。后续构筑需要验证这一可行性，避免把所有战斗成长都设计成无法拒绝的孵化行为。

## 十二、与 0.1 的接口

现有切片已经可以原地长进这套设定，不需要推翻：

| 0.1 现有 | 在世界观中的位置 |
| --- | --- |
| 接收厅 | 座天使的口腔／前台，工人登记的地方 |
| 压力车间与压力机 | 心泵外围的循环限流装置，持续压迫一段血管并将供给导向母机；停机后该段循环恢复 |
| 短弧 / 探针 | 牧者提供的第一批检修战斗工具，能承载主角的神性；后续圣痕强化加速诱发潜能，同时向初啼输送供给 |
| 02:14 求救与日志 | 圣骸真实求救被记录的时间戳，后续可用于比对模仿声音 |
| 回溯与 stage 2 存档 | 母机的第一次自检，FW 1.0 → 1.1 |
| B-17 | 通往井道的门，战役入口 |
| 供给记录（模块预签收） | 工人早已把「献祭」写成了流程 |

0.1 作为心泵外围的序章切片接入战役。上述生理对应与后续揭示是设定方向，需要后续补入场景、交互和文案。其余腔室需要各自的行动、战斗、证据与路线设计。

当前压力机是序章验证用首领。正式 29 关编排可将其循环预警、开板与闪避机制用于第一组守门人，或保留为可选教学；不额外叠加一场必经战斗。正式区域脏器、中心合并与武器铺尚未实现。

### B-17 首次身体揭示的场景方向

门后是一条仍在使用的检修井。主角沿梯下降，发现井壁上的电缆扎进同一种组织。牧者提示切开一段「堵塞物」可以取得升级材料。圣骸通过尚未被完全接管的渠道，首次发出清楚的阻止。

台词草案为「别切。那是我用来听见你的地方。」

玩家可停止操作、检查接线和原件，或继续提取。后续回应读取实际行动。这段场景需让玩家辨认感觉组织，并看见停止或继续操作带来的具体变化；其资源参数与下一轮回响仍待设计。

## 十三、待定

- 21 个小怪关的机制差异、七次区域成长与各组恢复节奏
- 单轮时长的实测校准
- 七个守门人的具体招式与节奏
- 结局数量是否需要收敛（六个是否太多，尤其「换班」这类彩蛋结局）
- 公众信奉的「天使」实为古神这一骗局，在玩家流程中何时揭示，对外宣传透露到哪一层
- 从下列候选中选定正式标题，开发代号暂用《夜班回路》
- 圣骸受拘束的可操作部件，以及它对初啼和玩家行动的具体回应
- 提取、拾取、携带和装配的计量边界；基础战斗工具与低吸收路线的可行性
- 累计吸收的难度上限、七组顺序、脏器逐次接入的实际选择、重叠结局条件与低吸收要求
- 29 关的时长与死亡恢复、七次商店更新的经济预算、武器替换与装备效果的平衡
- 如何在回溯后的设施重建与记录中持续核实局部营救的成果
