targetFinish: 可在 Windows Godot 中完整游玩的重构切片，采用 ART-1.0 像素场景、角色、HUD 与反馈。

更新于 2026-11-10。ART-1.0 适用《夜班回路》0.1 及后续所有资产批次。本文件定义制作标准，首批场景、主角、压力机和 HUD 已进入切片。当前范围与实机覆盖见 [产品范围](PRODUCT_BRIEF.md) · [游戏策划案](GAME_DESIGN.md) · [QA 报告](../qa/QA_REPORT.md)。

## 1. 核心方向：冷光工业，血肉显形

熟悉的厂房、检修桥、继电器、搪瓷标签与供给管线，在探索和回溯后逐渐显露活体结构。玩家最初能理解这些设施的用途，之后才发现机器的结构与身体器官同构。工业实用主义是表层，湿件与古神是深层。

四条全局规则：

1. **关掉辉光仍能游玩。** 剪影、色块、接触阴影与实体发光芯先成立，光晕只做第二层。
2. **每种亮色有固定职责。** 危险、交互、道路与异常有不同形状编码；剧情反转不能篡改操作提示。
3. **大结构先于碎细节。** 人物、可走地面、威胁先读到；纹理不能把走道切碎，也不能把背景做成粒子噪声。
4. **同一物件在多轮中变异。** 电缆分叉像神经、阀门收缩像瓣膜、系统卡槽像椎骨；保留原位置和主要轮廓，使玩家能比较变化。

主角使用短检修外套、偏置工具包和单侧工牌灯。压力机以外露管道和前部护板区分警告、开板和停机。母体的偏轴夹持架和层叠供给腔属于后续关卡候选。角色、建筑和标识均沿用本作原创设计。

2026-11-12 的 0.2 批次采用新增[生体工厂原型板](visual-targets/夜班回路：生体工厂原型板.png)与[武器原型板](visual-targets/夜班回路：武器原型原型板_gbc.png)中的钢架包裹脏器、机械接口长出组织、扑击体／盾形守卫／感染工人的轮廓，以及电弧刃／长探针／气动枪的握持差异。首批先制作心泵外围测试组，正式七区顺序仍待关卡验证。原型板的其他武器和古神剪影不代表它们已进入游戏。

本批仍使用原色板与 640×360 场景网格：敌人用 64×64 透明画布承载约 24–48 像素主体与前摇变形，三姿态横排；武器用 64×32 画布保留长枪轮廓，装备图标保持同等源像素。PixelFX 命中与收集效果经重配色烘焙，危险边界最后绘制；低动效用短静态标记表达相同结果。中心接入后只添加对应心核、局部搏动与低频心跳，不改变交互和危险的颜色语义。

## 3. 镜头、轮廓与尺寸（镜头假设下的生产规格）

Windows 横屏，世界逻辑画布 **640×360**，最近邻整数放大：1280×720 为 2×、1920×1080 为 3×、2560×1440 为 4×。其他尺寸按最大可容纳整数倍居中留边，禁止横向拉宽或分数缩放基础像素层。UI 单独按 1280×720 逻辑画布排版，装饰线的屏幕粗细对齐世界像素；文字不强塞进低分辨率世界层。

固定斜俯视、能看见地面与立面；角色正立绘制，不用倾斜钻石网格。透视规则跨批次一致。探索优先看玩家与下一条通路；战斗优先看玩家、伤害边界、敌人前摇。重要物遮住玩家时退淡遮挡层，玩家脚点和危险边界始终保留；装饰不可覆盖玩家主体超过 15%。

| 资产 | 源像素规格 | 轮廓与共用约束 |
| --- | --- | --- |
| 主角 | 32×48 画布，实体约 24×40 | 约 4 头身，肩宽约 14–18；四向基准；底部中央脚点 (16,44) |
| 人形 NPC / 敌人 | 32×48 或 48×48 | NPC 敞开、圆角；敌人前倾/楔形；不只换色区分 |
| 大型敌人 / Boss | 96×96，必要时 128×128 | 主体约主角 2–3 倍高；攻击部件与中央核分离；体积不等于碰撞盒 |
| 环境模块 | 32×32 地块；立面高度按 16 递增 | 行走区保持低纹理密度，入口净宽至少 64；实际碰撞待玩法验证 |
| 道具 / 拾取物 | 16×16、32×32 | 同类共底座；证据为缺角纸片/封签，装备依器物轮廓识别 |
| 物品 / 技能图标 | 24×24，四边留 2 | 主轮廓、一个内记号；状态图标 16×16；禁用缩小插画充数 |
| 特效 | 32/64/128 方形画布 | 像素芯与辉光层分开；威胁面积由实际规则决定 |
| 对话头像 | 96×96 | 继承头型、衣领、工牌位置，禁止突然变成高清厚涂 |
| 加载 / 宣传母版 | 640×360 或同像素密度的重构画面 | 平台版式另排；不把横图硬裁成竖图，不虚构尚不存在的玩法 |

世界基础轮廓 1 源像素，关键交互/危险边界 2 源像素。连续边缘用稳定阶梯，禁止散乱锯齿与抗锯齿糊边。人物用 3 档主体明暗，材质通常不超过 4 档。环境、角色与粒子都用同一源像素网格；镜头位移对齐网格，防止亚像素抖动。阴影沿场景主光方向落地，不给所有人物贴同一个黑椭圆。

## 4. 材质与光照层级

| 材质 | 最小画法 | 变异后仍保留的结构 |
| --- | --- | --- |
| 涂漆钢板 | 夜蓝大面、冷钢边，少量雾钢直线缺口 | 拼缝位置保留，缝内出现肉灰连接 |
| 混凝土 | 石板色块、两三处大缺损，避免全表面抖点 | 裂缝向供给节点聚拢，不改变可行走判读 |
| 黄铜 / 旧管道 | 焦土阴影、黄铜面、骨白短高光 | 弯头变为关节，接口仍可辨 |
| 布料 | 两三块哑光色，无金属长高光 | 衣物变化不抹去人物工牌与包的位置 |
| 湿件 | 血肉暗与肉灰弧形团块、少量尖锐湿高光 | 血肉沿已有管网生长，不铺满地面 |
| 显示窗 / 发光芯 | 深色实体框、单色亮芯、1–2 像素反光 | 原方形卡槽可开裂，交互括号保持一致 |

合成优先级：**危险边界与玩家识别 > 可交互物/目标 > 建筑受光 > 气氛粒子与辉光**。常规光晕半径 2–6 源像素，峰值不透明度建议 ≤20%，Boss 大光源 ≤10 像素；需在叠加实测后调低。可走地面与相邻遮挡至少相隔一档底色。黑区也要留墙脚、栏杆断面或地灯提供空间信息。

血肉显形不等于全屏泛红：初期工业结构完整，中期暴露接口，后期显露供给器官；同机位逐步替换材质。危害仍须警红和边界，背景肉色不冒充伤害提示。

## 5. UI、文字与叙事

UI 是检修铭牌与槽式终端：深底、阶梯角、单线框、扁平色块。焦点用青色括号+位置变化；选中用实心卡扣；不可用为暗底+锁图标+原因。禁用不能只降透明度。物品稀有度如后续采用，用缺口数/边框形状+文字，不扩展彩虹色。

在 1280×720 实际显示尺寸：中文正文 **20px**、功能标签 **18px**、说明下限 **16px**；标题 28–40px。字体先用本机可用中文无衬线，发行时选择有明确许可的字库。文字允许正常清晰栅格化，像素风由容器与图标承担。提供 100/125/150% 字号，150% 应换行/扩展布局而非截字。正文对底色的工程验收目标 ≥4.5:1，控件边界/关键图形 ≥3:1；低对比色板组合不用于必读内容。

按钮热区至少 44×44 显示像素、相邻间距至少 8px；键鼠焦点都可见。常驻信息只放玩法实际存在的状态：当前目标左上，玩家状态下方，短通知右上。证据、装备与技能进入各自面板，不先虚构资源条或行动顺序。

对白区在视口下方 25%，每行 22–28 个汉字、每页最多 3 行；姓名、历史回看、立即显示全文与下一句分开。阅读页底衬不透明。人物态度用朝向与距离变化表达：信任时面向玩家，怀疑时半转身，拒绝时退至通路边；这不新增数值关系系统。玩家与对话者在画面中部各占约 8–15% 高度，关键手势无遮挡。

瞬时文字不得穿过玩家脚点或伤害边界：

| 类别 | 芯色 | 描边/底衬 | 指定验证帧 |
| --- | --- | --- | --- |
| 命中数值（若玩法采用） | 骨白 | 深墨 2 源像素描边 | `03-pressure.png` 中间调地面、红色警戒区旁 |
| 交互 / 证据反馈 | 青亮或骨白 | 不透明深墨底衬 | `02-exploration.png` 终端前 |
| 敌方意图 / 状态 / 危险 | 骨白，警红只做图形 | 不透明深墨底衬 | `03-pressure.png` 敌人前方 |
| 回溯 / 章节题签 | 骨白 | 夜蓝整块底衬 | `01-title.png` 标题保护区 |

目标图仅验证区域预留；最终中文字形、对比、150% 排版和色觉模拟须在实机另验。

## 6. 动画、特效与声音

运行画面以 60Hz 流畅呈现为目标，逐帧美术默认 8–12fps；事件提示按毫秒计时，不由动画帧数反推战斗窗口。四向待机每向 4 帧/约 800ms，行走每向 6 帧/约 600ms；攻击动作数量与前后摇等待战斗形式确定。

| 动词/反馈 | 输入与过程 | 结果与转场 | 声音形制 |
| --- | --- | --- | --- |
| 选路线 / 交互 | 80ms 括号收拢 | 120ms 卡扣落位；拒绝保留原因 | 短继电器点击；拒绝为干涩双击 |
| 探索 / 取证 | 工牌灯缓慢呼吸，周期 1800–2400ms | 证据实体亮 120ms，右上提示停 1200ms | 鞋底/金属台面、纸片与夹扣 |
| 选技能 / 装备 | 焦点 80ms；未确认不播放装备结果 | 确认后 180ms 插槽接合 | 陶瓷开关与低频接通声 |
| 战斗 / 命中 | 前摇方向靠轮廓与地面边界；时长由玩法定 | 轻击 60ms 亮芯+120ms 碎屑；重击 80ms+180ms；禁止改动模拟时间 | 金属短击→低频结构共振；生物层为闷响 |
| Boss 胜利 / 核实 | 威胁消退后再出现成果 | 300ms 灯熄、600ms 通路/证据显露；胜利不清除待调查事实 | 机器卸压、继电器释放，留证据提示声 |
| 战败重试 | 取消危险动画，显示原因 | 250ms 静暗，直接重试入口；不播放母体迭代 | 低沉停机，不用回溯音型 |
| 主动回溯 | 明确确认后才开始 | 200ms 灯向内收、300ms 错位轮廓、300ms 同机位复位 | 反向机械节拍，回到原工厂环境声 |

禁止全屏高频闪烁。受击闪只改变角色局部，不让背景随之白屏；光脉冲 ≤2Hz。粒子不得盖住警戒边线，玩家周围至少 12 源像素不叠装饰碎屑；最多 3 簇显著冲击同时显示，超额删装饰而不是删危险信息。

“减少动态效果”关闭镜头震动、视差、反向拖影与亮度脉冲，用固定轮廓、图标与文字保留反馈；回溯可跳过演出，但仍显示迭代结果。音效优先级为危险→输入/结果→环境，避免机器噪声淹没提示。音乐取工厂低频、克制节拍和稀薄持续音；不因像素风默认采用欢快 8-bit。语音范围 `none`：当前台词与人物未定，先以文字、动作和音效建立表达。

## 8. 动态连续性边界

本轮不规划视频或实时 3D。以下约束用于环境循环和回溯演出。

| 动态条目 | 角色 / 时长 / 状态 | 分级与降级 |
| --- | --- | --- |
| 终端与管网微光 | 氛围，1800–2400ms 循环，只在可见时播放 | 可降级：静态亮芯 |
| 回溯关键帧 | 表达已确认的迭代，800ms，确认后到下一轮 | 可降级：旧/新状态静帧+结果文字 |

| 参考包 | 内容要求 |

| LOCATION_SHEET | 同机位工业/暴露/孵化三状态；通路、相机和地标一致 |

| 对象 | 持久事实 / 临时事实 | may_control / must_not_control |
| --- | --- | --- |

## 9. 批次纪律与验收

必需资产：主角四向、可走地面/遮挡/入口、首个敌人与 Boss 轮廓、交互终端、证据物、危险边界、UI 控件与图标、加载静帧、菜单与结果页。每项缺失均不能宣称该切片美术完成。

可降级资产：角色待机与环境循环→静态帧；额外肖像表情→朝向/距离；光晕→实体亮芯；回溯动画→前后静帧与文字；宣传专用插画→通过验收的游戏画面加标题。分级不代表这些资产已经制作。

每批记录：视觉版本 `ART-1.0`、镜头假设、源尺寸/脚点、色板、动画时长、用途、原创/授权来源。先做一个房间验证，再扩产；后续请求单个资产时继承本规范，只改变该资产内容，不另选画风。

短禁用清单：彩虹霓虹；泛白 bloom；模糊基础精灵；一片纯黑的必经路；不同像素密度混搭；背景红光冒充危险；细碎噪声铺地；对白缩成像素蚂蚁；一味复刻参考图大门与人物；用宣传画冒充已实现画面。

验收时在 720p 与 1080p 实际尺寸检查：关辉光仍辨玩家/出口/敌人；灰度与色觉模拟下用形状辨交互/危险；叠三簇冲击仍见攻击边界；UI 150% 不裁字；同物件跨状态保持地理一致。0.1 已采集 720p 实机代表帧，精修及对比度、性能、动态遮挡专项待验。[视觉目标与实机对照](VISUAL_TARGETS.md)
