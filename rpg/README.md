# 夜班回路（开发代号，正式名称待定）

主角称为 09。当前为 **0.2.3 · 动作、音频与界面**，开放调查序章、首组四关、中心接驳／购物和肺叶入口遭遇。完整战役的每关目标、成长预算与六种结局见 [29 关路线](../design/LEVEL_ROUTE.md)。

Windows 本机可双击[试玩启动器](../试玩重构版.cmd)，它会查找仓库上两级目录的 Godot 4.5.1。也可用 Godot 4.5.1 导入本目录的 [project.godot](project.godot)，等待图片导入完成后按 F5。

0.2 在标题选择「开始首组远征」，选择基础武器后从中心右侧出发。三个小怪关依次检验扑击、感染工人攻击和免疫守卫的正面护甲；清理敌人后靠近右上出口按 E。第四关守卫核心开放时可伤，击败后取得心核并回中心。中央 E 接入心核，左侧 E 打开武器铺，右侧 E 再出发；完成肺叶入口后显示本版终点。

短弧为近身扇扫，探针长枪可窄线贯穿，压力铆枪为远距高频单体点射。心核共鸣使每次命中伤害 +1，首次武器位强化使伤害 +2，换武器保留等级。首版只开放一个装备位：加固护具使耐久上限 +2，回路电容使攻击恢复加快 15%，两者替换。

首组三个小怪关各奖励 6 工料，Boss 奖励 12，共 30。每件商品 12、首次强化 10、每批最多刷新一次且花 6。第一批保证压力铆枪用于验证新武器，其他货品从有限池抽取；库存、售出状态与刷新次数随远征保存。战败终止本轮；暂停中的「重新远征」也会清空本轮构筑。未完成关卡的退出继续会回到入场状态。

当前世界由 `world.gd` 的独立地板、墙、柱、门、管线和机械部件组合，不加载整房间背景。`rpg/art/modular/` 存放 64 个角色／敌人姿态帧与 12 个模块的图集及元数据；执行 `python rpg/art/index_modular.py` 可重建 SpriteFrames、区域、脚点和握持点，不修改 PNG。[制作提示词](art/modular/PROMPTS.md)。09 用六帧前／后行走及四帧动作片段，三类小怪各 12 个姿态；动作跟随原有规则时钟。Boss 用独立护板、锤臂、活塞与心核部件，世界按脚点排序。场景仍为 1280×720 渲染、640×360 玩法坐标。

原 `painted/` 的人物定妆与房间图保留作造型／材质参考，武器和装备图仍用于持物或 UI。旧绘图脚本只保留为历史来源。当前仍需精修全方向动作、握持点和帧间一致性。[动态实机](../qa/modular-motion.gif)。

新增特效可用 `node rpg/art/build_expedition_fx.mjs` 从本地 PixelFX 烘焙，沿用 [MIT 声明](art/combat/PIXELFX_LICENSE) 与 [署名](art/combat/PIXELFX_NOTICE.md)。

| 操作 | 键位 |
| --- | --- |
| 移动 | WASD |
| 交互 / 开门 / 查看记录 | E，靠近提示点 |
| 选择模块 | 1 / 2，或点击按钮 |
| 攻击 | J 向面朝方向攻击，或鼠标左键瞄准 |
| 闪避 | 空格，沿当前移动方向 |
| 暂停 / 关闭弹窗 | Esc |

空格发动约 0.16 秒的短闪，冷却 0.70 秒。按住 WASD 决定方向，松开方向键时沿面朝方向闪避。短闪可以取消攻击前摇。落击接触时处于短闪保护，会出现青色残影、环形余波与“擦身闪避”提示。同一次落击在保护结束后不会再次补伤。过早短闪后仍留在攻击轨迹里会受伤。

压力机和压维守卫以箭纹的朝向区分纵向压降和横扫，带状标记显示受击宽度。落击时箭纹转为骨白，锤臂动作配合碎屑和地面震波。

扑击体的虚线圈标记落点，感染夜班工的窄轨迹沿举起的扳手朝向锁定，免疫守卫的扇形标记盾击范围。低动效保留静态轨迹与命中时的骨白反馈。 [实机动态](../qa/enemy-trajectories.gif)

有效命中会短暂保持接触姿势，Boss 的机体反冲、金属碎屑和装甲裂纹表现损伤。主角受伤会取消尚未出手的攻击，并出现玫红火花与踉跄。耐久耗尽后约 1.2 秒内依次受击、倒地、脱手与暗化，再出现重试按钮。低动效采用短标记和两档倒地姿态。

短弧电切刃用骨白亮芯近身劈开弱点。探针长枪用窄束命中远处开板口。撞上护板会弹开灰白火花并发出短促金属声。箭纹出现后沿侧边离开轨道，看到青色核心提示再打。停机后靠近右侧日志终端。

主动确认回溯时写入 B-17 检查点，进入旁路读完供给记录后再次保存。标题的「继续调查」从最新检查点继续。战败重试重开当前轮，「重新调查」清除切片进度。存档使用 Godot 的 `user://night-shift.cfg`，应用数据目录为 `BossCompanyRebuild`。

标题和暂停都能打开设置。文字按 25% 一档从 100% 调到 200%，低动效、震动和减弱闪光可分别设置。主音量、音乐、环境、战斗与界面音量可独立调节，音量设置保存在 `user://audio.cfg`。1280×720 为原生显示，大窗口按整数倍居中，小窗口等比缩小。场景沿用 [ART-2](../design/ART_DIRECTION.md)。

靠近柜台、接驳台或出口时，底部显示实际可用的交互。09 的脚点能沿底座滑动，闪避也会被关门和门柱挡住。门扇打开后中间通路放行，从可交互距离按 E 切换房间。

## 战斗与环境反馈

连续点按 J 或左键可衔接短弧三段挥击；最后 120ms 内按下的攻击／闪避可短暂缓冲，过早按键不无限排队。闪避会取消攻击前摇和排队攻击，暂停、受伤与换房也会清理队列。

短弧普通命中保持接触姿势约 55ms，第三段约 75ms。探针约 30ms，铆枪约 18ms，Boss 停机一击约 100ms。顿帧期间仍可移动或闪避，敌方预警按原速度推进。冷灰破环表示格挡，玫红与琥珀碎屑区分组织和金属命中。

09 的动作由 `AnimationPlayer` 同步驱动身体帧、武器角度与握持位移，跟随走动、蓄力、出手、闪避、受击与倒地状态。脚步随实际移动触发。音乐围绕工厂低频底色与同步的危险层混音，预警或重击时短暂让出音乐音量。

战斗房间边侧的冷却罐可打碎，相邻罐会延迟反应；此版本仅提供视觉反馈，不造成伤害或发放资源。碎屑有离地高度、重力、反弹与落地痕迹，蒸汽上升；换房或重开清除。最多 240 个活动粒子、96 个表面痕迹，低动效关闭震动和局部光并减少粒子。尚无完整的逐像素液体、燃烧或地形破坏模拟。

## 像素特效制作

[基础战斗资源](art/combat/effects.tres)由 `node rpg/art/build_combat_fx.mjs` 烘焙，包含刀痕、脉冲、短闪与倒地尘屑。[接触与敌方攻击资源](art/expedition/effects.tres)由 `node rpg/art/build_expedition_fx.mjs` 烘焙，包含护板格挡、组织与金属火花、Boss 碎环和敌方攻击。Godot 直接读取导出的资源。

[PixelFX](https://github.com/patch-gg/pixelfx) 用于离线生成特效精灵表。本机源码位于 `.runtime/pixelfx-tools/`，固定在 `044e12a45dc9cc312cec50ee606dfc98afe5adc2`。工具使用 Node.js 18 或更新版本。在仓库根目录复现探针命中方向的导出样例：

```powershell
$opts = '{"palette":["#07141F","#102738","#244454","#237C83","#57E4CE","#829499","#DFE8D5"],"stone":"#49616B","light":0.25}'
node .runtime/pixelfx-tools/tools/render.mjs impacts/bullet-impact --sheet --no-actor --opts $opts --out .runtime/pixelfx-preview
```

样例生成透明 PNG、帧数据 JSON 和预览图。进入 Godot 的特效使用最近邻采样，按 JSON 的帧矩形、时长与锚点配置。审查以游戏内像素尺寸为准，保留红色预警的形状与对比度，遵循 [ART-2](../design/ART_DIRECTION.md)。分发采用的资产时保留 [LICENSE](https://github.com/patch-gg/pixelfx/blob/044e12a45dc9cc312cec50ee606dfc98afe5adc2/LICENSE) 和[上游署名](https://github.com/patch-gg/pixelfx/blob/044e12a45dc9cc312cec50ee606dfc98afe5adc2/NOTICE.md)。

在仓库根目录运行 `& ./rpg/验证.ps1` 可复现 Godot 原生渲染与输入验证。独立的无窗口 UI、动作、混音和碰撞检查入口为 `res://tests/presentation_systems.gd`。[游戏策划案](../design/GAME_DESIGN.md) · [构建说明](../design/BUILD_BRIEF.md) · [QA 报告](../qa/QA_REPORT.md)
