# Godot 单人起步版 v0.1

当前引擎：Godot 4.5.1 标准版；原生 2D／GDScript／Control，无外部依赖。Windows 桌面中文、单人离线。

## 运行

用 Godot 4.5.1 导入本目录 `project.godot`，打开工程后按 F6/F5；首次选择东亚、西欧或北美西岸。
点击黄色简历获得招聘点，右侧购买升级，悬停查看效果和前置。顶部暂停与快进，事件自动暂停，结算后重开。
空格切换暂停；重开已有对局需确认。

通过命令行运行（替换成本机引擎路径）：

```powershell
& 'C:/Users/xudic/Desktop/R/Game/Godot_v4.5.1-stable_win64.exe' --path ./godot
```

本机也可从仓库根目录运行 `& ./godot/运行原型.ps1`；其他成员用 `-Godot '引擎路径'` 指定自己的4.5.1。

从项目根目录执行机制回归：

```powershell
& ./godot/验证.ps1 -Godot '本机/Godot_v4.5.1-stable_win64.exe'
```

脚本等待引擎真正结束并返回退出码；测试账目文件仅用临时测试名，真实玩家存档不参与回归。
测试脚本只重定向当前进程的 APPDATA 到项目 `.runtime`，不改变系统设置。图形实机验证单独记录。

## 接手入口

- `simulation.gd`：员工人数、招聘传播、升级效果、事件、胜负、唯一游戏时间、存档。
- `data/content.json`：12 地区及连接、12 升级、4 事件；从浏览器原型迁入。改配置后运行回归。
- `main.gd`／`main.tscn`：地图画面、HUD、升级、起点／事件／结果弹窗、鼠标与快捷键。
- `tests/verify.gd`：稳健与高压路线、暂停、存档恢复、升级前置、重开。
- `../本周任务与接手清单.md`：经营、美术、测试、发行的可认领任务与验收。

模拟每1秒推进1个旧原型游戏日，1×/2×/4×只改变模拟推进速度。未来财务周接这里的游戏时间，不读系统时钟。
普通地图状态持续运行，事件和重开确认暂停；快进遇事件停止剩余推进。财务面板尚未制作。

## 当前边界

这是招聘原型，尚无订单、工资、现金、贷款、经济危机、方针与资本市场预览。现金与欠薪胜负条件将在经营合流时接入。
自动路线第1230个模拟日获胜只证明当前旧规则可达，不证明真人时长或新经营规则平衡。
原生窗口实机已验证高压扩张、第1139日反制失败及结算后重开；完整真人胜利和单局节奏仍待试玩。
首版使用原生矢量轮廓与系统中文字体，尚未制作正式美术、音频、设置或教学流程。

保存位置：`user://hiring-v1.json`，正常运行在 Godot 用户数据目录。自动每10个模拟日及关键操作保存，退出时保存。
存档带版本和随机状态；读到损坏／未知版本时保留原文件，确认重开后才允许覆盖。浏览器存档与此版本不互通。
首版只支持同格式存档，修改字段时需同时更新版本与读取逻辑。

尚未交独立 Windows EXE。准备对应4.5.1导出模板后使用 Windows 导出；`*.json` 必须包含在非资源导出过滤器中。
