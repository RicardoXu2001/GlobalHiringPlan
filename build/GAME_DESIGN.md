# OPC 与招聘合流设计基线

experienceProfile: 地图驱动的实时扩张策略，允许暂停思考，以全球人人入职为终局。

继承现有地图招聘玩法与2026-11-02批准的OPC增量经营开局，保留单人中文、离线、暂停思考的体验。

核心动作：
- 接单：看工作量、启动费、报酬及回款时点，承担一项业务。
- 开工与交付：创始人按时间推进有限工作量，完成后交付，得到现金或应收。
- 投资：花现金升级工具/接单流程；招聘点继续解锁三条组织能力路线。
- 雇佣与扩张：完成首雇，开启或暂停地图招聘，沿固定连接扩张。
- 应对：选择事件、调接单偏好、查看财务并保留工资储备，结算后重开。

三段弧：开局以首笔回款和工具升级为标记；成长期以首雇及自动接单为标记，工作从本人执行转为员工执行；扩张期新增地区和招聘网络，需求、产能、工资与监管一起变化。胜利是全地图人人入职且无欠款，失败为反制100%或两周救援期到期仍有欠款。

规则不变量：
- 金额以整数分累计，现金只因实际回款增加；交付延期单只增加应收，到期只回款一次。
- 员工逐日累计工资，财务周60模拟日。同日先收款、执行交付，再付账单；新增招聘从下一日计薪。
- 工具、首雇和订单启动费即时支付，现金不足时拒绝动作；周结不足转欠款，不能隐式透支。
- 两周救援期限从首次不足起固定；部分回款和再次欠款不延长。新收入优先补欠款。
- 订单需求由起始及已覆盖地区人口决定、每周刷新；自动化仍需有效订单和产能。暂停新增招聘仍计薪。
- 暂停可安排经营，工作与账目不推进；财务阅读和事件停止模拟，快进逐日结算并在事件处停下。
- 当前订单、工作进度、应收、累计工资、自动化和随机状态随对局保存；重载不重抽、不重复发初始资金或领奖。
- 经济新局和旧招聘档分开，损坏/未知格式不被自动覆盖。

最小验证：一份短单手工交付、现金升级、一份延期订单到账、首雇、员工自动执行、自动接单和地图增长；固定10人案例40+60回款-60工资-8运营=32元，回款延期时先欠28元，实际到账后补齐。过度扩张30人时工资180元+运营8元，期初40元导致148元缺口。机制路线另验完整全球胜利与高压失败。

当前经济使用一份共享订单队列、固定工资与区域人口需求上限；后续可按试玩决定是否需要独立地区业务。金融与危机将在这套现金流上扩展。趣味、节奏和长期平衡需真人验证。
